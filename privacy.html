Политика конфиденциальности

Версия 1.0 · 21 мая 2026

1. Какие данные мы собираем

1.1. Email — при регистрации. Используется как идентификатор аккаунта и для входа.

1.2. Результаты скрининга — баллы по школам терапии, определённый «тип героя», код рекомендованной школы. Сохраняются в привязке к аккаунту (если вы авторизованы) или анонимно.

1.3. История чата — сообщения, которыми вы обмениваетесь с AI-терапевтом. Хранятся для обеспечения непрерывности сессии.

1.4. Мы НЕ собираем: имя, фамилию, телефон, адрес, IP, платёжные данные (платежи обрабатываются платёжным провайдером), данные банковских карт.

2. Как мы используем данные

2.1. Email — для аутентификации и связи по вопросам аккаунта.

2.2. Результаты скрининга — для показа вашей персональной статистики и агрегированной анонимной статистики.

2.3. История чата — для обеспечения работы AI-терапевта. Сообщения передаются в DeepSeek API для генерации ответов.

3. Передача данных третьим лицам

3.1. Сообщения чата передаются в DeepSeek API (deepseek.com) для обработки AI-моделью. DeepSeek имеет собственную политику конфиденциальности.

3.2. Мы НЕ продаём, не передаём и не раскрываем ваши данные третьим лицам, кроме случаев, предусмотренных п. 3.1 и требований законодательства.

3.3. Агрегированная анонимная статистика (без привязки к email) может быть использована для улучшения Сервиса.

4. Хранение данных

4.1. Данные хранятся в базе SQLite на сервере, расположенном на платформе Render (render.com, США).

4.2. Срок хранения: пока существует ваш аккаунт. При удалении аккаунта все связанные данные удаляются.

4.3. Пароли хешируются (bcrypt) и не хранятся в открытом виде.

5. Ваши права

5.1. Вы имеете право запросить информацию о хранящихся у нас данных.

5.2. Вы имеете право потребовать удаления ваших данных. Для этого свяжитесь с нами (контакты в разделе 7).

5.3. Вы можете удалить аккаунт самостоятельно — все связанные данные будут удалены.

6. Cookies и трекеры

6.1. Сервис использует localStorage для хранения JWT-токена авторизации в вашем браузере. Это не cookie, данные не передаются автоматически.

6.2. Сервис НЕ использует рекламные трекеры, Google Analytics или аналогичные системы слежения.

7. Контакты

По вопросам конфиденциальности и удаления данных: создайте Issue в репозитории github.com/Msilith/therapy-funnel.

8. Изменения политики

8.1. Политика может обновляться. Пользователи будут уведомлены о существенных изменениях.
