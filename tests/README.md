# TherapyVoid — автотесты (Playwright)

E2E- и data-тесты для веб-фаннела TherapyVoid. Написаны на **Playwright + TypeScript**.

## Что покрыто

| Файл | Что проверяет |
|------|----------------|
| `funnel.spec.ts` | Основной сценарий: выбор скрининга (быстрый 5 / полный 15), прохождение вопросов, навигация назад/вперёд, экран результата с победившей школой, рестарт |
| `i18n.spec.ts` | Локализация RU/EN: переключение на лету, `?lang=`, сохранение в localStorage, смена языка прямо во время теста |
| `locales.spec.ts` | Целостность локалей: одинаковый набор ключей RU/EN, 5 «быстрых» вопросов, у каждого вопроса ≥2 варианта с валидной школой, у каждой школы есть герой и рекомендация |
| `smoke.spec.ts` | Доступность всех статических страниц и файлов локалей |

Итого — 4 набора, 20+ проверок. Прогон идёт против статического сервера (`serve`), **база данных и бэкенд не нужны**.

## Запуск

```bash
npm ci                 # установить зависимости
npx playwright install chromium   # скачать браузер (один раз)

npm test               # все тесты
npm run test:headed    # с открытым браузером
npm run test:ui        # интерактивный UI-режим Playwright
npm run report         # открыть HTML-отчёт после прогона
```

Тестовый сервер поднимается автоматически (`npx serve -l 4173 .`), поднимать вручную ничего не нужно.

## Структура

```
playwright.config.ts   # конфиг: webServer, baseURL, проекты chromium + mobile
tests/
  funnel.spec.ts
  i18n.spec.ts
  locales.spec.ts
  smoke.spec.ts
```

## CI

Workflow `.github/workflows/playwright.yml` гоняет тесты на каждый push/PR, отчёт сохраняется артефактом.
